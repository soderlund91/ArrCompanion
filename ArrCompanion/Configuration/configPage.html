Arr Companion — Help

Sonarr & Radarr for Home Screen Companion's missing titles
What does this plugin do?
It adds the titles Home Screen Companion finds missing from the library to Sonarr and Radarr: by hand, or with rules. It reads Home Screen Companion's missing_titles.json, so Home Screen Companion needs Settings › Show missing titles on, and on its Missing tab, under Export (shown at the Advanced settings level), Keep the list in a file with JSON.
playlist_addMissing

Every title on the file that is not in the library, with its poster and its place on each list ("Trending #1"). Filter by list, top places and All / Movies / Shows, search by title or IMDb id, sort, and switch between the list and posters.

+ Radarr / + Sonarr adds a title; ✓ Radarr / ✓ Sonarr means it is there already (point at it for monitored, downloaded or episodes). In Sonarr / Radarr also shows the titles Sonarr or Radarr has but the library does not have yet; the browser remembers it.

Click rows to select them, then Add selected or Hide. Hidden titles are under Show hidden; rules leave them alone. The Add dialog picks the root folder, quality profile, monitoring and search; it starts on the root folder last added to on that server, else the one under Settings.

The tab opens at once with what Sonarr and Radarr held the last time they were read, reads them again meanwhile and updates the rows when they answer.

ruleRules

A rule takes a list (or any list), movies, shows or both, the top places, and optionally a first year and a limit per run. Preview shows what it picks, and why it picks nothing. Rules use the root folder and quality profile set under Settings.

They run on the scheduled task Arr Companion › Run rules (every 6 hours) and, when that is on, a few minutes after the file changes. Save and run now shows what they pick and asks before adding. A title a rule has added once is never added again.

historyHistory

What was added, by hand or by which rule, from which place on which list, to which server, and the result.

settingsSettings

Servers: Sonarr and Radarr, each with its URL and API key, Test Connection, and the defaults for new titles (root folder, quality profile, monitoring, search). Emby's server talks to Sonarr and Radarr; the API keys never reach the browser.

List & poster settings: the missing titles file (empty reads Home Screen Companion's file; a file or folder here reads that one instead) and a TMDb key for the posters (empty uses Home Screen Companion's).
